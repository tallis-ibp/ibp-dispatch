# Operating Model

This is the current understanding of how the schedule works. Update this file as the scheduling team teaches more rules.

## Schedule Structure

- Each sheet tab is one week.
- Days run Monday through Sunday.
- The sheet is visually split:
  - Monday, Tuesday, Wednesday use the crew names on the left.
  - Thursday, Friday, Saturday, Sunday use the repeated crew names in the middle.
- Filled day cells are the planned job/project/task for that crew on that day.
- Blank day cells are not automatically available. They need diagnosis:
  - actually available
  - not scheduled yet
  - unavailable
  - carryover work expected
  - waiting on material
  - waiting on logistics
  - needs helper/equipment before it can be assigned

Trailer capacity notes (from field observations):
- 5 TN base is at or beyond some trailers' practical limit — causes brake stress
- Large deck jobs (7 TN base) need 2 driver trips — must be flagged in brief
- Gooseneck required for heavy coping deliveries and machine transport

Trailer colors used in dispatch: Noel identifies trailers by color (rojo, azul, amarillo, verde). Dispatch must specify which color trailer to use.

## Constraint Logic

A good schedule needs to check:

- crew skill fit
- crew size
- reliability risk
- project size
- job type
- job number/client type
- location and distance
- material readiness
- equipment needs
- trailer needs
- driver availability
- Wilson availability
- customer promise date
- carryover from prior days/weeks
- whether a blank cell is truly open
