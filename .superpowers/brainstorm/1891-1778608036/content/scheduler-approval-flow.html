Scheduler Approval Flow

How should the scheduler approve the daily schedule from their phone?

A

Telegram-first Recommended

Every morning the bot sends a summary to the scheduler's personal Telegram. One tap to approve and dispatch all crews.

Scheduler's Telegram (personal chat with bot)
📋 Schedule Ready — Tuesday May 13

SANTIAGO → Gilroy #600049 (Deck)
PENNA → Natalia Gove #170829
WAYPE → Pine Tree #800003
TOBY → Favilla #280608 (Coping)
FAUSTO → OFF

⚠️ 2 flags: Penna missing gate code, Toby material unconfirmed

Auto-sends at 6:30 AM if no response
✅ Approve & Send ✏️ Open Dashboard 🚫 Hold

Tapping Approve & Send dispatches all crews instantly. Open Dashboard opens the mobile web app to edit first. Hold pauses auto-send and alerts the scheduler.

B

Mobile Dashboard only

Scheduler opens the web app on their phone browser to review and approve. No Telegram interaction for the scheduler themselves.

Mobile browser — dashboard
SANTIAGO
Gilroy #600049
● Ready
PENNA
Natalia Gove
⚠ Gate code missing
APPROVE ALL

Pros:
• Full edit capability
• See all details

Cons:
• Must open browser
• Slower than Telegram

C

Both — Telegram quick-approve + Mobile dashboard

Telegram for the 80% case (just approve), dashboard for when edits are needed. Same as Option A but making it explicit both channels work.

Flow:
  1. Bot sends morning summary to scheduler's Telegram
  2. No issues → tap Approve & Send → done in 5 seconds
  3. Issues → tap Open Dashboard → fix on mobile browser → approve
  4. No response by 6:30 AM → bot sends reminder
  5. Still no response → auto-hold (does NOT send without approval)
