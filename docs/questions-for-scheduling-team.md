# Questions For The Scheduling Team

Use these questions to improve the automation rules.

## Crew Fit

- Which crews are approved for far-away jobs?
- Which crews should not be sent to certain builders or customer types?
- Which crews can do coping without supervision?
- Which crews can do tri-level pool decks?
- Which crews can handle turf, retaining walls, or concrete prep?
- Which crews need helpers for which job sizes?

## Blank Cells

- When a cell is blank, how do we tell if the crew is actually available?
- Are there hidden carryover expectations not written on the schedule?
- Where are vacations, sick days, and no-work days tracked?

## Monday Boards

- Which monday board is the source of truth for active jobs?
- Which monday board is the source of truth for logistics?
- Which columns indicate material readiness?
- Which columns indicate job priority or customer promise date?
- Which columns identify driver/trailer/skid steer needs?

## Logistics

- How many of each trailer type are available?
- Which trailers require which truck/driver?
- Which jobs require Noel or Arthur specifically?
- Which skid steers exist, and what jobs require each type?
- How far in advance must materials be staged?
- When Wilson is on concrete pump or forming work, who covers warehouse/fleet needs?

## Job Numbers

- Confirm the meaning of job number prefixes:
  - 17
  - 27
  - 28
  - 30
  - 57
  - 60
  - 80
